Dev OS Package Manager สำหรับ Linux ใช้คำสั่ง `dev` ติดตั้ง `.dpk`, `.dpkx`, `.tar.gz`, `.deb` และ `.rpm` จากไฟล์หรือ HTTP(S) URL

### ใหม่ในรุ่นนี้: ติดตั้งจาก `.deb` และ `.rpm`

```sh
dev install hello-tool_2.3_amd64.deb
dev install "https://example.com/releases/hello-tool-2.3-1.x86_64.rpm" --sha256 <digest>
dev run hello-tool
```

- อ่านแพ็กเกจ Debian และ RPM ได้โดยตรง ไม่ต้องมี `dpkg`/`rpm` และไม่ต้องใช้ root รองรับ payload แบบ gzip, xz และ zstd (ไม่รองรับ bzip2)
- ไฟล์ถูกแตกลง store ของ `dev` (ไม่ใช่ `/usr`) ผ่านการตรวจ path, ขนาดและ checksum ชุดเดียวกับ `.dpk` จึงใช้ `dev verify`, `--replace`, `dev rollback` และ `dev remove` ได้เหมือนเดิม
- ชื่อ รุ่น และคำอธิบายอ่านจาก `control` ของ deb หรือ header ของ rpm (`--name` / `--version` ใช้แทนได้) และสร้างคำสั่งอัตโนมัติจากไฟล์ที่รันได้ใน `usr/bin`, `usr/sbin`, `usr/local/bin`, `bin`, `sbin`
- ไม่รัน maintainer scripts ไม่แก้ dependency และข้าม symlink/hard link/ไฟล์พิเศษพร้อมแจ้งเตือน ไบนารีที่ลิงก์แบบ dynamic ต้องมีไลบรารีในระบบอยู่แล้ว
- `.deb`/`.rpm` ไม่มีข้อมูล release จึงอัปเดตด้วย `dev install <ไฟล์ใหม่> --replace` (`dev update` ไม่ครอบคลุม)

### ติดตั้ง `dev` ด้วย `.deb` / `.rpm`

release นี้แนบแพ็กเกจของ `dev` เองสำหรับ x86_64 (`amd64`) และ arm64 ติดตั้งที่ `/usr/bin/dev`:

```sh
# Debian / Ubuntu
sudo apt install ./dev-os-package-manager_0.6.0_amd64.deb
# Fedora / RHEL / openSUSE
sudo dnf install ./dev-os-package-manager-0.6.0-1.x86_64.rpm
```

หมายเหตุ: `dev self-update` แทนที่ไบนารีที่รันอยู่ ถ้าติดตั้งที่ `/usr/bin` ต้องรันด้วยสิทธิ์ root หรืออัปเดตผ่าน package manager ของระบบ

### อื่น ๆ
- เพิ่ม workflow CI (build, test และ smoke test บน x86_64 กับ arm64) และ workflow release ที่บิลด์แต่ละสถาปัตยกรรมบน runner จริงแล้วตรวจ checksum ก่อนเผยแพร่

รวมทุกอย่างจาก 0.5.0 รวมถึง `dev self-update`, `dev update`, การเชื่อมกับ Dev OS desktop และรายการ `.desktop` ให้ Launcher

ไฟล์ดาวน์โหลด:
- `dev-linux-x86_64`, `dev-linux-arm64`: ไบนารี static musl สำหรับ Linux x86_64 และ arm64
- `dev-linux-x86_64.tar.gz`, `dev-linux-arm64.tar.gz`: ไบนารี `dev`, ตัวติดตั้ง และเอกสาร
- `dev-os-package-manager_0.6.0_*.deb`, `dev-os-package-manager-0.6.0-1.*.rpm`: แพ็กเกจของ `dev` สำหรับ amd64/x86_64 และ arm64/aarch64
- `hello-1.0.0.dpk`, `hello-1.0.0.tar.gz`, `greeting-extension-1.0.0.dpk`: แพ็กเกจตัวอย่าง
- `SHA256SUMS`: checksum ของไฟล์ดาวน์โหลด

ติดตั้งไบนารี:
```sh
case "$(uname -m)" in aarch64) ARCH=arm64;; *) ARCH=x86_64;; esac
curl -fL "https://github.com/d-osc/DevOsPM/releases/latest/download/dev-linux-$ARCH" -o dev
chmod +x dev
mkdir -p "$HOME/.local/bin"
install -m 755 dev "$HOME/.local/bin/dev"
export PATH="$HOME/.local/bin:$PATH"
dev --version
```

ตรวจ checksum ของไฟล์ที่ดาวน์โหลดด้วย `sha256sum --ignore-missing -c SHA256SUMS`

ทดสอบก่อนเผยแพร่: unit tests 56 กรณี (รวม 6 กรณีของ `.deb`/`.rpm` ที่ใช้ gzip, xz, zstd, hard link ใน rpm และไฟล์เสียหาย) และ CI บน Linux x86_64 กับ arm64 ผ่าน ยังไม่ได้ลองกับแพ็กเกจจริงจาก Debian/Fedora
