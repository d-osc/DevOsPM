Dev OS Package Manager สำหรับ Linux ใช้คำสั่ง `dev` ติดตั้ง `.dpk`, `.dpkx`, `.tar.gz`, `.deb` และ `.rpm` จากไฟล์หรือ HTTP(S) URL — รุ่นนี้มาพร้อม **implementation ใหม่ด้วยภาษา DevLang** ควบคู่กับไบนารี Rust

### ใหม่ในรุ่นนี้

- **รุ่น DevLang ของ `dev`:** ชุด source `.dev` ใน `devlang/` ทำงานทดแทนไบนารี Rust ได้ครบทุกคำสั่ง (`install`, `list --json`, `info`, `verify`, `remove --purge`, `rollback`, `run`, `pack`, `update`, `self-update`) โดยใช้ runtime `d` (DevLang ≥ 0.5.5) แทนการ build แยกสถาปัตยกรรม
  - registry, layout ของ store, shim และ Extension Store ของ Dev OS **เหมือนรุ่น Rust ทุกไบนารี** ทั้งสองรุ่นอ่าน store ของกันและกันได้ (ทดสอบ cross-install ครบทั้งสี่ทิศทางใน CI)
  - ติดตั้งด้วย `sh devlang/install.sh` (ต้องมี `d` บน PATH) หรือดาวน์โหลด `dev-cli.tar.gz` จาก release นี้
  - ความต่างที่ตั้งใจไว้: ตรวจทุกพาธใน archive ก่อนแตกไฟล์แล้วตรวจซ้ำหลังแตก, hash ด้วย `sha256sum` หลังดาวน์โหลดก่อนใช้งานเสมอ, `.deb` ต้องมี `ar` (binutils), `.rpm` ยังไม่รองรับในรุ่น DevLang, `dev run` แสดงผลหลังคำสั่งจบ (exit code ตรงเป๊ะ) และไม่มี spinner — รายละเอียดทั้งหมดใน `devlang/README.md`
- **`dev self-update` ของรุ่น DevLang:** สลับชุด source จาก asset `dev-cli.tar.gz` ของ release ล่าสุด โดยตรวจ SHA-256 จาก API และรัน `--version` ของชุดใหม่ก่อนสลับเสมอ (รุ่น Rust ยัง self-update ไบนารีเหมือนเดิม)
- **CI ครอบคลุมรุ่น DevLang:** ทุก push รัน unit tests, smoke test แบบ end-to-end, ทดสอบ `install.sh` และ cross-compatibility กับไบนารี Rust ทั้ง x86_64 และ arm64 ส่วน release จะ build และตรวจสอบ `dev-cli.tar.gz` ก่อนเผยแพร่ทุกครั้ง

รวมทุกอย่างจาก 0.6.4, 0.6.3, 0.6.2, 0.6.1, 0.6.0 และ 0.5.0 รวมถึง PATH shims, `dev update`, การเชื่อมกับ Dev OS desktop และรายการ `.desktop` ให้ Launcher

ไฟล์ดาวน์โหลด:
- `dev-linux-x86_64`, `dev-linux-arm64`: ไบนารี static musl สำหรับ Linux x86_64 และ arm64
- `dev-linux-x86_64.tar.gz`, `dev-linux-arm64.tar.gz`: ไบนารี `dev`, ตัวติดตั้ง และเอกสาร
- `dev-os-package-manager_0.7.0_*.deb`, `dev-os-package-manager-0.7.0-1.*.rpm`: แพ็กเกจของ `dev` สำหรับ amd64/x86_64 และ arm64/aarch64
- `dev-cli.tar.gz`: รุ่น DevLang (source `.dev` + launcher + ตัวติดตั้ง) ใช้ได้ทุกสถาปัตยกรรม สำหรับ `dev self-update` หรือติดตั้งเองเมื่อมี `d` แล้ว
- `hello-1.0.0.dpk`, `hello-1.0.0.tar.gz`, `greeting-extension-1.0.0.dpk`: แพ็กเกจตัวอย่าง
- `SHA256SUMS`: checksum ของไฟล์ดาวน์โหลด

ติดตั้งไบนารี:
```sh
case "$(uname -m)" in aarch64) ARCH=arm64;; *) ARCH=x86_64;; esac
curl -fL "https://github.com/d-osc/DevOsPM/releases/latest/download/dev-linux-$ARCH" -o dev
chmod +x dev
mkdir -p "$HOME/.local/bin"
install -m 755 dev "$HOME/.local/bin/dev"
export PATH="$HOME/.local/bin:$PATH"
dev --version
```

ตรวจ checksum ของไฟล์ที่ดาวน์โหลดด้วย `sha256sum --ignore-missing -c SHA256SUMS`

ทดสอบก่อนเผยแพร่: unit tests ของรุ่น Rust ผ่านบน Linux x86_64 และ arm64 รุ่น DevLang ผ่าน unit tests 21 กรณี, smoke test end-to-end (pack → install → run → shim → Launcher → `--replace` → rollback → extension → ตรวจจับแก้ไขไฟล์ → remove), `install.sh`, cross-compatibility สี่ทิศทางกับไบนารี Rust และ `dev self-update` เต็มขั้นบน mirror ทดสอบ
