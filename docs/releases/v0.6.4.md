Dev OS Package Manager สำหรับ Linux ใช้คำสั่ง `dev` ติดตั้ง `.dpk`, `.dpkx`, `.tar.gz`, `.deb` และ `.rpm` จากไฟล์หรือ HTTP(S) URL

### ใหม่ในรุ่นนี้

- **เรียกคำสั่งได้ตรงๆ:** หลังติดตั้งแอป พิมพ์ `code` ได้เหมือน `dev run code` `dev` สร้าง shim สคริปต์เล็กๆ ไว้ข้างไบนารี `dev` (ซึ่งอยู่ใน PATH อยู่แล้ว เช่น `/usr/bin`) หรือที่ `$DEV_BIN_DIR`
  - shim มีเครื่องหมาย `# dev-shim: package=<ชื่อ>` และ `dev` แก้หรือลบเฉพาะไฟล์ที่มีเครื่องหมายนี้ ถ้าชื่อซ้ำกับไฟล์ของระบบ (เช่น `/usr/bin/code` จาก apt) จะข้ามพร้อมแจ้งเตือน และยังใช้ `dev run <คำสั่ง>` ได้
  - ต้องมีสิทธิ์เขียนโฟลเดอร์นั้น ถ้า `dev` อยู่ที่ `/usr/bin` ให้ติดตั้งด้วย `sudo` หรือตั้ง `DEV_BIN_DIR=$HOME/.local/bin`
  - อัปเกรด, `dev rollback` และ `dev remove` ปรับหรือลบ shim ให้ตามรุ่นที่ใช้งานอยู่ `--no-desktop` ปิดทั้งไอคอนและ shim

หมายเหตุ: `.deb`/`.rpm` ที่มีไบนารีคนละสถาปัตยกรรมกับเครื่อง (เช่น amd64 บน arm64) จะติดตั้งได้แต่รันไม่ได้ (Exec format error) ยังไม่มีการเช็กสถาปัตยกรรมตอนติดตั้ง และยังไม่รัน maintainer scripts หรือแก้ dependencies

รวมทุกอย่างจาก 0.6.3, 0.6.2, 0.6.1, 0.6.0 และ 0.5.0 รวมถึง `dev self-update`, `dev update`, การเชื่อมกับ Dev OS desktop และรายการ `.desktop` ให้ Launcher

ไฟล์ดาวน์โหลด:
- `dev-linux-x86_64`, `dev-linux-arm64`: ไบนารี static musl สำหรับ Linux x86_64 และ arm64
- `dev-linux-x86_64.tar.gz`, `dev-linux-arm64.tar.gz`: ไบนารี `dev`, ตัวติดตั้ง และเอกสาร
- `dev-os-package-manager_0.6.4_*.deb`, `dev-os-package-manager-0.6.4-1.*.rpm`: แพ็กเกจของ `dev` สำหรับ amd64/x86_64 และ arm64/aarch64
- `hello-1.0.0.dpk`, `hello-1.0.0.tar.gz`, `greeting-extension-1.0.0.dpk`: แพ็กเกจตัวอย่าง
- `SHA256SUMS`: checksum ของไฟล์ดาวน์โหลด

ติดตั้งไบนารี:
```sh
case "$(uname -m)" in aarch64) ARCH=arm64;; *) ARCH=x86_64;; esac
curl -fL "https://github.com/d-osc/DevOsPM/releases/latest/download/dev-linux-$ARCH" -o dev
chmod +x dev
mkdir -p "$HOME/.local/bin"
install -m 755 dev "$HOME/.local/bin/dev"
export PATH="$HOME/.local/bin:$PATH"
dev --version
```

ตรวจ checksum ของไฟล์ที่ดาวน์โหลดด้วย `sha256sum --ignore-missing -c SHA256SUMS`

ทดสอบก่อนเผยแพร่: unit tests 62 กรณี (รวม 3 กรณีของ shim) และ CI บน Linux x86_64 กับ arm64 ผ่าน ยังไม่ได้รัน shim บน Linux จริง และยังไม่ได้ลองกับแพ็กเกจจริงจาก Debian/Fedora
