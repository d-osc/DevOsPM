แก้การแสดงสถานะติดตั้งและรายการแอปใน Applications

- แสดงสถานะเตรียมติดตั้ง รอ package store แตกและตรวจไฟล์ บันทึกแพ็กเกจ และสร้าง launcher
- แพ็กเกจที่ไม่มี manifest ค้นหาคำสั่งจาก bin directories, executable ที่ราก archive และ Exec ในไฟล์ .desktop ที่อ้างถึง executable ภายในแพ็กเกจ
- อ่านชื่อแอปและไอคอนจาก .desktop และใช้ไอคอนมาตรฐานเมื่อไม่มีไอคอนในแพ็กเกจ
- Launcher ระบุ package store ที่ติดตั้งจริง เพื่อเปิดแอปได้แม้ใช้ --root
- แจ้งเตือนเมื่อไม่พบคำสั่งเปิดแอปและไม่สามารถสร้างรายการ Applications ได้

อัปเดตด้วย `dev self-update` แล้วติดตั้งแพ็กเกจเดิมซ้ำด้วย `dev install <file> --replace` เพื่อสร้าง launcher ใหม่

ยังไม่รัน maintainer scripts หรือแก้ dependencies ของ .deb/.rpm และไม่ได้รับประกันว่าแอปที่ต้องใช้ absolute system paths จะทำงานจาก package store ได้ ไม่มีการเปลี่ยนแปลงข้อจำกัดเหล่านี้ในรุ่นนี้

การตรวจสอบก่อนเผยแพร่: Rust tests 62 กรณีผ่านบน Linux ผ่าน WSL รวมการสร้าง launcher จาก manifestless .dpk/.tar.gz และแพ็กเกจ Debian; workflow release จะทดสอบและทำ smoke test บน x86_64 และ arm64 ก่อนเผยแพร่ไฟล์พร้อม SHA256SUMS
