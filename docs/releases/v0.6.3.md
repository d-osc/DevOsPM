Dev OS Package Manager สำหรับ Linux ใช้คำสั่ง `dev` ติดตั้ง `.dpk`, `.dpkx`, `.tar.gz`, `.deb` และ `.rpm` จากไฟล์หรือ HTTP(S) URL

### ใหม่ในรุ่นนี้

- **spinner ตอนติดตั้ง:** `dev install` แสดงแต่ละขั้น (เตรียม, ดาวน์โหลด, เปิด store, แตกไฟล์, บันทึก, ลงทะเบียน launcher) พร้อม spinner ที่เปลี่ยนเป็น `✔` เมื่อจบ หรือ `✘` เมื่อล้ม บนเทอร์มินัลเท่านั้น ถ้า stderr ถูก redirect หรือ `TERM=dumb` ยังเป็นบรรทัดธรรมดา ตั้ง `NO_COLOR` เพื่อปิดสี
- **ชื่อเรียกสั้น:** `dev add` / `dev i` = `install`, และ `dev uninstall` / `dev un` / `dev rm` = `remove`
- **`dev remove` ลบไอคอนใน Applications ครบขึ้น:** นอกจากคำสั่งใน manifest แล้ว ยังกวาดไฟล์ `dev-*.desktop` ทุกไฟล์ที่มีเครื่องหมาย `X-DevOS-Package=<ชื่อ>` และบอกโฟลเดอร์ที่ลบไม่สำเร็จ

หมายเหตุ: `.deb`/`.rpm` ที่มีไบนารีคนละสถาปัตยกรรมกับเครื่อง (เช่น amd64 บน arm64) จะติดตั้งได้แต่รันไม่ได้ (Exec format error) ยังไม่มีการเช็กสถาปัตยกรรมตอนติดตั้ง และยังไม่รัน maintainer scripts หรือแก้ dependencies

รวมทุกอย่างจาก 0.6.2, 0.6.1, 0.6.0 และ 0.5.0 รวมถึง `dev self-update`, `dev update`, การเชื่อมกับ Dev OS desktop และรายการ `.desktop` ให้ Launcher

ไฟล์ดาวน์โหลด:
- `dev-linux-x86_64`, `dev-linux-arm64`: ไบนารี static musl สำหรับ Linux x86_64 และ arm64
- `dev-linux-x86_64.tar.gz`, `dev-linux-arm64.tar.gz`: ไบนารี `dev`, ตัวติดตั้ง และเอกสาร
- `dev-os-package-manager_0.6.3_*.deb`, `dev-os-package-manager-0.6.3-1.*.rpm`: แพ็กเกจของ `dev` สำหรับ amd64/x86_64 และ arm64/aarch64
- `hello-1.0.0.dpk`, `hello-1.0.0.tar.gz`, `greeting-extension-1.0.0.dpk`: แพ็กเกจตัวอย่าง
- `SHA256SUMS`: checksum ของไฟล์ดาวน์โหลด

ติดตั้งไบนารี:
```sh
case "$(uname -m)" in aarch64) ARCH=arm64;; *) ARCH=x86_64;; esac
curl -fL "https://github.com/d-osc/DevOsPM/releases/latest/download/dev-linux-$ARCH" -o dev
chmod +x dev
mkdir -p "$HOME/.local/bin"
install -m 755 dev "$HOME/.local/bin/dev"
export PATH="$HOME/.local/bin:$PATH"
dev --version
```

ตรวจ checksum ของไฟล์ที่ดาวน์โหลดด้วย `sha256sum --ignore-missing -c SHA256SUMS`

ทดสอบก่อนเผยแพร่: unit tests 59 กรณีและ CI บน Linux x86_64 กับ arm64 ผ่าน ตรวจผลที่ spinner เขียนออกมาแล้ว แต่ยังไม่ได้ดู animation บนเทอร์มินัลจริง และยังไม่ได้ลองกับแพ็กเกจจริงจาก Debian/Fedora
